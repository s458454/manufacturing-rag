## 2. v3 只补五条已确认 failure family

在 `b1-router-v2` 正文上做最小修订，不换 few-shot 原句：

1. `direct` 单任务 `task.query` 必须逐字复制，包括标点、语言、空白；英文保持英文。
2. 独立任务 >8 → 只能 `task_limit` 且 `tasks=[]`，禁止输出第 9 个 task。
3. 当前 Query 缺关键对象且历史能唯一补全 → `confirm_rewrite`，禁止静默 `direct`。
4. 历史不能唯一补全，或对象/标准号未在历史出现 → `clarify`，禁止虚构实体。
5. 问助手能力、用法、已接入数据/文档类型 → `system`。

v3 正例仍是 v2 的四条，**没有**写入 v2 holdout 的 11 个 FAIL 原句。
