## 4. A3.1 实现口径

### 4.1 输入 / 输出

```text
LoadedMarkdownDocument.content
  → parse_markdown_document()
  → ParsedMarkdownDocument
       headings / tables / page_markers / terminal_sections
  → profile_documents()
  → JSON（token 分布；不发 Leaf）
```

`LoadedMarkdownDocument.content` 不被修改（T15）。

### 4.2 Parser

```text
MarkdownIt("commonmark", {"html": True}).enable("table")
```

用 block token + source line map，不经 HTML 反推。`[CURRENT IMPLEMENTATION]`，不是永久架构约束。

### 4.3 Terminal Section

terminal span 是 **chunking 边界**，不是 A4 语义 Section。

| 情况 | 行为 |
|---|---|
| 无 child heading 的 heading | 该 heading 之后到下一同级/更高级 heading 之前 = 一个 terminal |
| 有 child 的 parent，且 heading 与首个 child 之间有非空正文 | 发出 **parent preface** terminal；不造假 heading |
| 首个 heading 之前有非空正文 | 发出 **lead** terminal，`heading_level=None` |
| 整篇无 heading | 一个 **document-root** terminal，`is_unheaded_document=True` |
| heading level jump（如 H1→H3） | **不**补假 H2 |
| 重复 heading 文本 | 允许；用行号 / ordinal 区分 |

heading 行本身不进入 `body_text`。`body_start_line = heading.end_line`。

### 4.4 Page marker

只认整行：

```text
<!-- PDF page N -->
```

`N` 为正整数。`<!-- TABLE ... page=N -->` 不是 page marker。

fail-fast：

- 文档没有任何 PDF page marker
- 第一个 marker 之前出现非空正文
- 页码倒退（同一页重复 marker 允许）
- 畸形 `<!-- PDF page ... -->`（含 `page 0`）
- 某行正文没有 active page

`body_text` / 未来 `Leaf.content` 去掉 page marker 行。`page_start` / `page_end` 由 span 内 marker 推导。

### 4.5 Table

`table_open`…`table_close` 的 source span 记为 `MarkdownTableSpan`。正文或 code fence 里的 `|` 不算表。A3.1 把整表当 atomic source span 统计 token；A3.2 切分时整表不拆行。

### 4.6 Token 计数

唯一入口：

```text
count_tokens(text, tokenizer)
  = len(tokenizer.encode(text, add_special_tokens=False, truncation=False))
```

禁止 `len(text)` / `split()` / `len(text)/4` / tiktoken / Qwen2.5 generation tokenizer。

A3.1 `without_body` 口径是 **token 数 == 0**。A3.2 空 span 口径见 §10。

## 5. A3.2 实现口径

### 5.1 Leaf schema（仅这 7 个字段）

```text
Leaf
  chunk_id      chk_ + sha256(canonical JSON)
  document_id   沿用 A1
  section_id    nearest semantic Section（见 §6）
  chunk_index   文档内 0-based，连续，不按 section 重置
  page_start    int ≥ 1
  page_end      ≥ page_start
  content       正文；无 heading prefix；无 <!-- PDF page N -->
```

`token_count` / `is_table` / `heading` / `document_title` **不是** Leaf 字段。CLI JSON 可另附 `token_count` 供验收，那是 debug artifact，不是持久化 schema。

`SectionRef`（给 A4 用，本轮不落 Section Store）：

```text
section_id
document_id
kind            "heading" | "document_root"
heading_level   heading 为 1–6；document_root 为 null
heading_text    heading 原文；document_root 为 ""
source_start    heading 行；document_root = 0
source_end      heading 行结束；document_root = 文档行数
```

`kind` **没有** `preface` / `lead`。

### 5.2 配置

`code/knowledge_base/chunking_config.py` 是 768/96 的唯一定义处：

```python
DEFAULT_CHUNK_SIZE = 768
DEFAULT_OVERLAP_TOKENS = 96
```

`chunk_size` 是普通可切分正文的 soft upper bound，不是 Table Atomicity 的绝对硬限制。非法配置 fail-fast：`chunk_size<=0`、`overlap<0`、`overlap>=chunk_size`。

### 5.3 Packing

对每个 **非空** terminal span：

1. `iter_section_blocks()` 列出 Markdown block（跳过 heading、空白、page-marker html）。
2. greedy：能装进当前 Leaf 的完整 block 就装。
3. 装不下就 flush，新 Leaf 从该 block 开始。
4. **单个非 table block >768**：flush 后对该块做 tokenizer sliding。
   - `tokenize_with_offsets()` 拿 token id + 字符 offset
   - window=768，overlap=96，stride=672
   - `Leaf.content = 原文切片`，**不用 decode 重写**
5. **单个 table >768**：flush 后发出 **一张完整 table-only oversize Leaf**。不按行切。
6. table ≤768：与普通 block 一样 packing；装不进当前 Leaf 就整表放到下一 Leaf。
7. 空白 / `strip()==""` 的 terminal：**0 Leaf**，不发 `content=""`。
8. 整篇 0 Leaf：**fail-fast**。

### 5.4 Overlap

只发生在 **同一 terminal span** 的相邻 Leaf。禁止跨 heading section。

上游修正（已落地）：

```text
overlap 计入下一 Leaf 的 768 budget
96 是可退让目标，不是硬配额
若 prev_overlap + next_body > 768 → 减少 overlap，必要时 0
禁止为凑满 96 切开完整 block
table 不作为 overlap 复制
token-window Leaf / oversize-table Leaf 不参与 block overlap
```

实现：从上一 Leaf 末尾向前取完整非 table block，直到再加一块会超过 `overlap_tokens` **或** 拼到下一 Leaf 后超过 `chunk_size`。一块都加不进则 overlap=0。

### 5.5 Page range

一个 Leaf 可能覆盖多段 source line range（overlap 会把上一块的行并入）。`page_start` / `page_end` 取这些 range 的最小/最大页。跨页 Leaf 必须记录真实页范围。

### 5.6 ID

canonical JSON：`sort_keys=True`，`separators=(",", ":")`，`ensure_ascii=False`。`sha256` 的 UTF-8 hex。无 uuid / time / `hash()`。

`section_id`：

```text
sec_ + sha256({
  document_id,
  heading_level,   # document_root 为 null
  kind,            # heading | document_root
  source_start     # heading 行，不是 preface body_start
})
```

`chunk_id`：

```text
chk_ + sha256({
  document_id,
  section_id,
  chunk_index,
  page_start,
  page_end,
  content
})
```

同一输入两次运行，ID 必须相同。content 或边界变化则 `chunk_id` 变。

## 6. Section identity（上游修正，已落地）

**A3.1 terminal span ≠ A4 语义 Section。**

每个真实 Markdown heading（包括有 child 的 parent）都有 `SectionRef`。`Leaf.section_id` 绑 **nearest semantic Section**：

| terminal span | Leaf.section_id |
|---|---|
| 末级 heading 正文 | 该 heading |
| parent preface | **父 heading**（不是合成 preface Section） |
| 首 heading 前 lead | `document_root`（`source_start=0`，`heading_level=null`） |
| 无 heading 整篇 | `document_root` |

绑定实现：`heading_for_terminal_section()` 用 `heading.end_line == section.body_start_line` 且 level 相同找到所属 heading；找不到且 `heading_level is None` 则 document_root。

### 12.2 `leaf_ids.py`（全文）

```python
"""Deterministic section_id / chunk_id for A3.2 Leaf identity."""

from __future__ import annotations

import hashlib
import json
from typing import Any


def _canonical_json(payload: dict[str, Any]) -> str:
    return json.dumps(
        payload,
        ensure_ascii=False,
        sort_keys=True,
        separators=(",", ":"),
    )


def _sha256_hex(canonical: str) -> str:
    return hashlib.sha256(canonical.encode("utf-8")).hexdigest()


def make_section_id(
    *,
    document_id: str,
    kind: str,
    heading_level: int | None,
    source_start: int,
) -> str:
    canonical = _canonical_json(
        {
            "document_id": document_id,
            "heading_level": heading_level,
            "kind": kind,
            "source_start": source_start,
        }
    )
    return "sec_" + _sha256_hex(canonical)


def make_chunk_id(
    *,
    document_id: str,
    section_id: str,
    chunk_index: int,
    page_start: int,
    page_end: int,
    content: str,
) -> str:
    canonical = _canonical_json(
        {
            "chunk_index": chunk_index,
            "content": content,
            "document_id": document_id,
            "page_end": page_end,
            "page_start": page_start,
            "section_id": section_id,
        }
    )
    return "chk_" + _sha256_hex(canonical)
```

### 12.4 packing / overlap（`leaf_chunker.py` 实现事实）

- `_pack_section`：table > chunk_size → oversize unit；非表 > chunk_size → `_sliding_units`；否则 greedy join，trial token 超限则 flush。
- `_sliding_units`：`stride = chunk_size - overlap_tokens`；`content = text[char_start:char_end]`。
- `_block_overlap`：token-window / oversize-table / 缺 blocks → 不加 overlap；否则从上一 Leaf 倒序取非表 block，同时受 `overlap_tokens` 与下一 Leaf `chunk_size` 约束。
- `_chunk_parsed_document`：`not section.body_text.strip()` 则 skip；发出后校验普通 Leaf ≤ chunk_size、page 合法、chunk_id 不重复、chunk_index 连续。
- `_build_section_refs`：需要 document_root 时发一条；然后每个真实 heading 一条；heading `section_id` 碰撞 fail-fast。
