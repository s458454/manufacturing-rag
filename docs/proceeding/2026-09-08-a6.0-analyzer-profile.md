## 5. 指标

判定：ICU 相对对照组，Recall@20 **少命中的 Query 数 ≤ 1** → 该侧可接受。英、中都可接受 → `UNIFIED_ICU`。

| Profile | Recall@5 | Recall@20 | MRR@20 | miss@20 |
|---|---|---|---|---|
| EN-STD | 0.933 | 1.0 | 0.673 | 0 |
| EN-ICU | 0.933 | 1.0 | 0.663 | 0 |
| CHN-BUILTIN | 1.0 | 1.0 | 0.961 | 0 |
| CHN-JIEBA | 1.0 | 1.0 | 0.944 | 0 |
| CHN-ICU | 1.0 | 1.0 | 0.978 | 0 |

Pairwise Recall@20：英 STD vs ICU、中 BUILTIN vs JIEBA、中 specialist vs ICU 均为 `both_hit=30`。

Co-hit rank（median Δ = 0）：

| 侧 | better / equal / worse |
|---|---|
| EN ICU vs STD | 3 / 23 / 4 |
| CHN ICU vs BUILTIN | 1 / 29 / 0 |

英文 ICU 的 MRR 略低于 standard（0.663 vs 0.673），未触发 Recall@20 失败规则。中文 ICU MRR 最高。

重复跑一遍（collection 名带 `r` 后缀）通过 `assert_repeatable`。

## 7. 已知限度（不得当成 D1）

1. **中文 Leaf 只有 25 个**（避雷器 2 / 仿真实训 11 / 充电 12）。避雷器正文几乎没有额定电压表，是 A0 投影损失，不是 Analyzer 问题。
2. 中文三个 profile 的 Recall@20 都是 1.0，**天花板效应**。不能据此声称 Jieba 无用，只能说在这 60 条 profiling Query 上 ICU 没有 Recall@20 损失。
3. Query 绑定当前 `chunk_id`，换 A0/A3 必须重绑，不能当 D1 Gold。
4. 本轮禁止把结论推广到 Hybrid/RRF/Query Rewrite。
