## 2. 设计口径（本轮）

- Parser：`MarkdownIt("commonmark", {"html": True}).enable("table")`，用 block token + source line map，不经 HTML 反推。
- Terminal Section：无 child heading 的 heading span；非空父级 preface 作为独立 terminal span（不造假 heading / 不造 `section_id`）。
- 无 heading：整篇为 document-root span，`heading_level=null`。
- Level jump（H1→H3）不补假 H2。重复 heading text 用 ordinal 区分。
- `<!-- PDF page N -->` 只用于 page_start/page_end，不计入 body token；heading 不计入 body token。
- Token：唯一 `count_tokens()` → `tokenizer.encode(..., add_special_tokens=False, truncation=False)`。
- 合法 Markdown table 为 atomic source span；正文/code fence 里的 `|` 不记表。
- A0 `<!-- TABLE ... page=N -->` 不是 PDF page marker。
- 缺 marker / 非法 marker / 页码倒退 / 正文出现在首个 marker 前：fail fast。
